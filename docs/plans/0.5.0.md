## Contracts the briefs must carry

- **Reference:** P1's captures are canonical, taken after fonts load. Light as in `emblems.mjs`; dark as in
  `lockup.mjs` (white ground shadow on, blue lifted to `#3d8bff`, ink `#f0f6fc`). Any departure is recorded there.
- **Geometry is the reference's:** five equal rounded panes at `-60, -46, -32, -18, -6` degrees, the gradient tile, TS
  in Open Sans 800 at the reference's placement. Flat's engine and defaults are not reused.
- **Engine and rendering:** a framework-free engine returns plain drawing data for an explicit `theme` (`light`,
  `dark`) and `detail`; a React adapter renders it; `standaloneSvg.ts` makes exports and `useOwnIdPrefix.ts` prefixes
  live ids. Output carries concrete values, no CSS custom properties, no `<use>` of outside symbols.
- **Display size:** the size helper takes the emblem's diameter in CSS pixels where it is seen, never the file's or
  canvas's pixel size. A slot seen at several sizes (the GitHub avatar) is drawn for its smallest.
- **Bounds:** sphere alignment, painted bounds (the blurred shadow) and square framing are defined separately.
- **Lockup:** Exo 2 700, unmodified letterforms, stacked, left-aligned; text size 0.4 of the emblem's diameter, gap
  10 at a 56 emblem, line height 1.05, as the reference.
- **Fonts:** Exo 2 is additive. The frozen studio's font loading and the scorer's font provenance are unchanged.
- **Contrast** (D9, 3:1): emblem and TS settled in P2, wordmark in P3, each against its local background (TS against its
  own tile), before P4's approval.
- **P4's gate:** the agent experiments freely; only the maintainer approves the detail steps, the breakpoints, each
  slot's detail and framing, and the single-slot backgrounds, from previews at real size including a circular
  avatar crop.
- **Assets:** the manifest lists each file (composition, canvas, theme or fixed background, detail, where shown); the
  generator writes exactly that set and nothing else, twice identically. PNGs come from resvg in Node; the studio
  downloads SVG. Favicon: SVG plus PNG (32 and 180); no ICO. The Meetup photo's exact size is checked when building
  (agent decides). Fixed-background images are the declared exceptions to light and dark pairs.
- **Frozen means unchanged:** under `src/concepts/` and `src/studio/` only what moving the old studio to
  `legacy.html` requires, and P5's one assertion. Flat's other tests and fixtures stay.
- **Verification:** both built pages; the legacy studio's three tabs, saved configurations and downloads still work;
  knip sees both entry graphs; drawing checked inline, as a standalone `<img>`, as a resvg PNG and, in P5, on a real
  GitHub README in both themes.
- **Files** split along seams within the 400-line cap, tests and manifest included.

## Decisions

Made with the maintainer on 30 October 2026, before this plan's pull request.

- **D1, the logo:** the sunset-fan bubble ("1" in the exploration); the blue fan is not kept.
- **D2, the old studio:** a previous version, frozen; the bubble gets a new studio from scratch, as simple as
  possible: preview at real sizes in both themes, and export. Tuning happens in code. Where it lives: D8.
- **D3, wordmark:** Exo 2, weight 700, stacked, "Type" upright in ink, "Script" in blue; the bubble's only. The frozen
  concepts keep their lettering.
- **D4, dark ink:** GitHub's near-white `#f0f6fc`, over white and cream.
- **D5, one-line lockup:** not in 0.5.0; it waits for a real banner, most likely a future LinkedIn group cover.
- **D6, single-slot images** (GitHub avatar, Meetup photo): one fixed background each, chosen in P4.
- **D7, the placeholder site:** 0.5.0 supplies its assets only.

- **D8, where the frozen studio lives:** a second page, `legacy.html`, its source paths unchanged, still built and
  tested; the new studio is the main page. Removing it from `main` (the signed `v0.4.0` release as the frozen copy)
  would need its own delicate cutover (the generator, the scorer, 44 test files and their dependencies together), so
  it isn't part of 0.5.0.
- **D9, contrast target:** 3:1, WCAG's level for large text and graphics, for every element against its local
  background. Today's colours pass: wordmark blue on white 4.4, lifted blue on GitHub dark 5.7, white TS on the tile's
  lightest blue 3.3. 4.5:1 would have forced a change to the brand blue.

## How each phase runs

As in [0.4.0's plan](0.4.0.md#how-each-phase-runs): a brief, a subagent in its own worktree that commits only, a
line-by-line review alongside ChatGPT Sol 6.1's (effort high), one combined pass, the gate and the **built** studio,
push once, CI, the maintainer's yes, `temple-bar merge`. P4's brief, being delicate, gets its adversarial review and
re-check first. The orchestrator checks each squash message keeps its `Reviewed-by` trailer.
